Widget do Bicho Hoje

Duas linhas de HTML. Nenhuma dependência. O crédito "Fonte: Bicho Hoje" vem junto por padrão.

<script src="https://cdn.jsdelivr.net/gh/babadada18790-ops/loteria-federal@main/docs/widget/bicho-widget.js"
        data-bicho-hoje data-limite="5" defer></script>

Atributos aceitos: data-limite (quantos prêmios mostrar, padrão 5) e data-api (apontar para outro JSON). O widget usa Shadow DOM, então o CSS do site que embute não vaza para dentro dele — e vice-versa.

Se a API falhar, ele mostra um link de volta para o site em vez de um espaço vazio. Isso é de propósito: falha silenciosa faz o site parceiro remover o widget.
